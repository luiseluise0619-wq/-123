# 사장님인사이트 — 제품 & 디자인 브리프

> 이 문서 하나로 신규 디자인을 의뢰할 수 있도록 제품의 내용·의도·목적·수익화·정보구조·디자인 방향을 정리한 핸드오프 문서.

---

## 1. 한 줄 정의

**서울 소상공인·예비창업자를 위한 "상권 데이터 경영 대시보드".**
"여기서 장사, 해도 될까?"에 실데이터와 AI로 답한다. 사장님용 블룸버그 터미널.

---

## 2. 누구를 위한, 왜

- **타겟**: ① 새 가게 자리를 고르는 **예비 창업자**, ② 이미 장사 중이고 확장/이전을 고민하는 **현직 사장님**.
- **문제**: 상권 정보는 흩어져 있고(서울 상권분석, 공판장 가격, 트렌드 따로), 대부분 "감(感)"이나 부동산 중개인 말에 의존. 데이터를 볼 줄 몰라서 못 본다.
- **해법**: 흩어진 공공 실데이터를 한 화면에 모으고, 등급·차트·AI 예측으로 **비전문가도 3초에 읽히게** 만든다.

---

## 3. 핵심 원칙 — 정직 (이게 제품의 정체성)

> **지어낸 숫자는 단 하나도 넣지 않는다.** 없으면 "없음"이라고 말한다.

- 모든 수치는 공공 실데이터에서 계산. 데모용 가짜 카드·목업 숫자 금지.
- 모델 성능은 **부풀리지 않고** 있는 그대로 표기(아래 6번). 못 하는 건 "못 한다"고 명시.
- 이 정직함이 곧 신뢰이고, 신뢰가 곧 유료 전환의 근거다. (경쟁 앱들의 화려한 "AI 추천"은 대개 근거 없는 연출)

---

## 4. 기능 구조 — 상권이 hero, 나머지는 서브

### ⭐ 메인: 상권 탐색 (항상 화면 중심)
1. **업종 선택 + 지역 검색** → 서울 상권을 **매출 등급(A+~F)**으로 줄세움.
2. **상권 자리 클릭** → 그 자리의 상세:
   - 방사형 프로필(매출/주말/여성/점포밀도/거래량)
   - 실측 지표(월매출·점포수·주말비중·여성고객)
   - **🔮 매출 전망**: 이 자리에 새로 들어갈 때 **예상 내 가게 월매출 + 성공확률 + 업종 내 위치**(AI 예측)
3. **지역별 드릴다운**(자치구→행정동)·**임대료별 필터** — *로드맵(9번)*.

### 서브: 시장 차트 (버튼으로 전환)
- **업종 매출**: 업종별 평균 월매출 막대
- **식자재 원가**: 공판장 실가격 전년대비 발산 막대(상승=원가위험)
- **가격 추세**: 주요 식자재 월별 도매가 꺾은선
- **데이터 출처**: 무슨 데이터를 어디서 쓰는지·갱신주기·모델 성능·정직 고지

### 우측 상시: 등급 기준 레퍼런스 (A+ 상위5% ~ F 하위20%)

|---|---|---|---|
| 상권 | 서울 상권분석서비스(우리마을가게) | 상권 1,087곳·36,566 업종별 자리, 월매출·점포수·유동인구·고객구성 | **분기별** |

## 6. AI 예측 — 정직한 성능 (숫자를 절대 부풀리지 않음)

**질문: "이 자리에 내 가게 내면 잘 될까?"** → LightGBM, 공간 홀드아웃(처음 보는 상권으로 검증).

| 예측 과제 | 성능 | 판정 | 비고 |
|---|---|---|---|
| **내 가게 성공확률**(점포당 매출 상위권) | **AUC 0.66** | 보통 | 동전던지기보단 확실히 나음 |
| **내 가게 예상 월매출**(점포당) | **R² 0.36** | 거침 | 액수보단 '될 자리인가' 판단용 |
| 상권 총매출 등급 | R² 0.47 | 주의 | 점포수가 합계를 끌어올린 **현황**이지 예측 아님 |
| 아는 상권 **다음 분기** 매출 | R² 0.80 | 가능 | **다분기 데이터 넣으면** 시계열 예측선 켜짐 |
| 식자재 단기 가격 | 관성 못 이김 | 무의미 | 백테스트 결과 "그냥 유지"가 더 정확 → 예측선 안 그림 |

**왜 겸손한 숫자인가**: 무료 공공데이터는 상권 단위 집계라, 개별 점포의 성패를 가르는 변수(브랜드·운영·임대료·목)를 다 담지 못한다. 정직하게 이게 한계다. → **정확한 액수 예측이 아니라 "될 자리 vs 위험한 자리" 선별**이 제품 가치.

**누출(leakage) 차단**: 거래건수·점포당매출 같은 '매출에서 파생된' 피처는 성능을 가짜로 부풀리므로 **의도적으로 제외**. (넣으면 AUC 0.99로 뻥튀기됨)

## 7. 수익화

**Freemium 구독 (SaaS).**

| | 무료 | **Pro (월 구독)** |
|---|---|---|
| 상권 등급·검색 | ✅ | ✅ |
| 상권 클릭 상세·성공확률 | 맛보기(상위 일부) | ✅ 전체 |
| 심층 차트(업종/식자재/추세) | 제한 | ✅ |
| **지역별·임대료별 필터·상권 비교** | ✕ | ✅ |
| **다음 분기 매출 시계열 예측** | ✕ | ✅ |
| 데이터 내보내기(리포트) | ✕ | ✅ |

- **핵심 유료 전환 포인트**: "여기 vs 저기" **상권 비교**, **임대료 대비 매출(수익성)**, **미래 전망**.
- 가치의 원천 = 흩어진 데이터를 모아 **의사결정 1건(수천만원짜리 창업 결정)**을 돕는 것. 월 구독료는 그에 비하면 저렴하다는 포지셔닝.
- 확장: 프랜차이즈 본사·부동산·컨설팅 대상 **B2B API/리포트**.

## 8. 현재 화면 구성 (정보 구조)

```
┌ 헤더: 로고 · 날짜 · 테마토글
├ 히어로: "여기서 장사, 해도 될까?" + KPI 타일 4개
│         (분석 상권 수 / A+ 상권 / 오늘의 원가경보 / 갱신주기)
├ 상권 탐색 (메인)
│   ├ 좌: 업종선택 + 검색 + 등급순 리스트
│   └ 우: 선택 상권 상세(방사형·지표·성공확률) + 등급기준
├ 시장 차트 (탭 버튼)
│   [🔮 매출전망(클릭연동)] [업종매출] [식자재원가] [가격추세] [데이터출처]
└ 푸터: 정직 고지
```

## 9. 로드맵 (미구현)

1. **임대료 병합** → 자치구/행정동별 임대료 조인 → "임대료 대비 매출(수익성)" 지표 + 임대료별 필터. *(가장 원하는 유료 기능)*
2. **다분기 상권 데이터** → 아는 상권 **다음 분기~내년 매출 시계열 예측선**(실선+점선+오차밴드, R²0.80). *(코드는 준비됨, 데이터만 넣으면 켜짐)*
3. 지도 뷰(상권 위치 시각화).
4. 상권 **비교**(2~3곳 나란히).

## 10. 신규 디자인에게 바라는 것

- **톤**: 신뢰감 있는 "데이터 터미널"이되 소상공인에게 **친근하고 안 무섭게**. 블룸버그의 밀도 + 토스의 명료함.
- **강조 순서**: ① 상권 등급/성공확률(의사결정), ② 매출 전망, ③ 시장 차트.
- **정직함이 보이게**: 성능 수치·데이터 출처·"못 하는 것"을 숨기지 말고 UI에 당당히. (겸손한 숫자가 오히려 신뢰를 준다)
- **모바일 우선**: 사장님은 현장/이동 중에 폰으로 본다.
- **차트가 상품**: 막대·꺾은선·도넛·방사형·분포 등 다양한 실데이터 시각화가 곧 가치이자 수익원. 차트 하나하나가 예쁘고 읽혀야 함.
- **다크/라이트** 둘 다.
- 피해야 할 것: 근거 없는 화려한 "AI가 추천!" 연출, 가짜 목업 숫자, 무의미한 장식.

## 11. 기술 스택 (참고)

- 백엔드: FastAPI(Python), LightGBM, pandas. 데이터: 서울 상권분석·aT 공판장.
- 프런트: 현재 단일 HTML 대시보드(자동 재생성). 재설계 시 프레임워크 자유.
- LLM: Gemini API(상담/요약용, 선택).
- 원칙: 환경변수로만 키 관리, 지어낸 데이터 금지.
