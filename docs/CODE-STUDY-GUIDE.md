# 내 프로젝트 코드 공부 가이드 (초보용)

> 이 문서는 "내가 만든 이 앱이 어떻게 돌아가는지"를 처음부터 이해하기 위한 안내서입니다.

## 0. 한 문장 요약

**"서울시 공공데이터를 파이썬으로 모아서(→ JSON 파일) 웹페이지가 그걸 읽어 지도·그래프·손익분기로 보여주는 앱"**

## 1. 큰 그림 (제일 먼저 이해할 것)

```
[서울시 공공 API]                     [내 저장소]                    [사용자 브라우저]
 상권분석·생활인구·임대료  ──①수집──▶  frontend/*.json  ──③읽기──▶  index.html (지도·진단)
 (data.seoul.go.kr)         (파이썬)   data-bundle.js              compare.html (비교)
                                          ▲                         building.html (건물)
                                          │②묶기                    trends.html (추이)
                                    build_bundle.py
```

- **① 수집**: `backend/collect_*.py` 파이썬들이 서울시 API를 호출해 데이터를 받아 `frontend/*.json` 파일로 저장
- **② 묶기**: `backend/build_bundle.py` 가 여러 JSON을 하나(`data-bundle.js`)로 합침 → 웹페이지가 한 번에 읽게
- **③ 읽기**: HTML 페이지들이 그 데이터를 읽어 화면에 그림
- **자동 반복**: 이 ①②③를 **GitHub Actions**(`.github/workflows/refresh-dashboard.yml`)가 매주/매월 자동 실행

👉 **핵심: 화면(HTML)은 데이터를 "실시간 계산"하지 않는다. 미리 만들어둔 JSON을 읽을 뿐.** (그래서 빠르고, 실시간이 아니라 주간/분기 갱신)

## 2. 파일 지도 — 뭐가 뭘 하나

### 화면 (`frontend/`)
| 파일 | 역할 | 미팅에서 |
|---|---|---|
| `index.html` | **메인**. 지도 + 진단(손익분기) + 데이터 토픽 + AI 상담 | 제일 중요. 여기 위주로 공부 |
| `compare.html` | 자치구/상권/임대료 **비교표** | 순수 자바스크립트(React 안 씀) → 읽기 쉬움 |
| `building.html` | 지도 클릭 → 그 지점 실시간 분석 | 카카오·건축물대장 API 씀 |
| `trends.html` | 연도별 추이 차트 | |
| `support.js` | index가 쓰는 **화면 그리는 틀**(프레임워크). 직접 만든 게 아니라 도구 | 안 봐도 됨 |
| `data-bundle.js` | 모든 데이터가 든 큰 파일 (`window.__SANGGWON`) | "데이터 창고" |
| `*.json` | 개별 데이터 (소비·매출·임대료 등) | |
| `vendor/` | React·Babel 원본 (외부 CDN 대신 자체 보관) | "안정성 위해 직접 보관" |

### 데이터 제공 (`frontend/api/`) — 서버에서 도는 코드
| 파일 | 역할 |
|---|---|
| `chat.js` / `insight.js` | AI 상담·요약 (Gemini 호출). **내 AI 키를 숨기는 중간 창구** |
| `building.js` / `kakao.js` | 건축물대장·카카오 지도 API 중간 창구 |
| `_ai.js` | 위 AI 파일들이 같이 쓰는 공통 코드 |

👉 **왜 중간 창구(api/)가 필요?** AI 키를 브라우저에 직접 넣으면 남이 훔쳐 씀 → 서버에서만 키를 쓰고 결과만 화면에 전달.

### 데이터 수집 (`backend/`)
| 파일 | 역할 |
|---|---|
| `collect_*.py` | 각 데이터 수집기 (매출·점포·소비·인구·임대료…) |
| `build_bundle.py` | 수집한 JSON들을 `data-bundle.js`로 합침 |
| `check_data.py` | **데이터 무결성 자동 점검** (깨진 값 감지) |

## 3. 데이터가 화면에 뜨기까지 — 실제 흐름 하나 따라가보기

예: "강남구 소비 구성"이 화면에 뜨는 과정

1. `collect_income.py` 가 서울시 소비 API 호출 → 자치구별 지출 비율 계산 → `income.json` 저장
   - 이때 **깨진 분기는 걸러내고 정상 분기만** 고름 (정직성)
2. `build_bundle.py` 가 `income.json`을 `data-bundle.js` 안에 넣음
3. `index.html` 이 로드되면서 `data-bundle.js`를 읽어 `this.income` 에 저장
4. 사용자가 '소득과 소비' 클릭 → `buildTopic('income')` 함수 실행
5. 그 함수가 강남구 데이터를 꺼내 **100% 누적 막대**로 그림 (`stackComp`)
   - 이때도 **값이 이상하면(한 항목이 55% 넘으면) 표시 안 하고 "보정 중"** (2중 안전장치)

👉 이 흐름 하나만 이해하면 나머지 데이터도 다 똑같은 구조예요.

## 4. 꼭 이해할 핵심 개념 5개

1. **정적 vs 실시간** — 데이터는 미리 만들어둔 파일(정적). 클릭할 때마다 서울시에 물어보는 게 아님. → 빠르지만 갱신은 주간/분기.
2. **data-bundle.js = 데이터 창고** — 화면은 이 하나만 읽으면 됨.
3. **진단(손익분기) 계산** — `index.html`의 `calc()` 함수. `손익분기 = 고정비 ÷ (1 − 원가율)`. 임대료·인건비는 입력 가능, 원가율 등은 업종 표준값(가정).
4. **데이터 정직성** — 없는 값은 안 지어냄. 실측/가정/폴백을 주석과 화면에 구분.
5. **무결성 점검** — `check_data.py`가 갱신 후 이상치를 자동 검사(소비가 깨진 걸 잡았던 그 장치).

## 5. 팀장이 물어볼 만한 질문 & 답 (미팅 대비)

**Q. 데이터는 어디서 오나요?**
> 서울 열린데이터광장 등 공공데이터입니다. 파이썬 수집기가 자동으로 받아옵니다. 공공누리 1유형이라 출처 표시하면 상업적 이용도 가능합니다.

**Q. 실시간인가요?**
> 아니요. 공공데이터 갱신 주기(주간~분기)에 맞춰 자동 갱신됩니다. 매출·소비 같은 건 원래 분기 단위로만 공개돼요.

**Q. 데이터 믿을 수 있나요?**
> 네, 실측 공공데이터 기반이고, 없는 값은 지어내지 않습니다. 게다가 갱신 후 이상치를 자동으로 잡는 점검 장치도 넣었습니다. (예: 소비 데이터가 특정 분기에 깨진 걸 발견해 자동으로 걸러내게 했습니다.)

**Q. API로 다른 서비스에 연동돼요?**
> 데이터가 JSON 형태라 연동 가능합니다. 브라우저 연동은 CORS 설정만 추가하면 되고, AI 기능은 키 보호를 위해 잠가둡니다.

**Q. 이거 혼자 만들었어요?**
> AI 개발 도구로 만들었고, 무엇을 만들지·어떤 데이터를 쓸지·어떻게 검증할지는 제가 판단했습니다.

**Q. 제품으로 키우려면?**
> 지금은 잘 작동하는 초기 버전(MVP)입니다. 대량 트래픽 대응, 사용자 인증, 안정성 보강이 다음 단계이고, 데이터가 공개 데이터라 가공·UX·해석으로 차별화하는 게 방향입니다.
