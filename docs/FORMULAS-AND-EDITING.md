# A. 공식은 어디서 가져왔나

## 계산 공식 (앱의 `formulas()` 에 근거까지 적혀 있음)

| 공식 | 식 | 출처·근거 |
|---|---|---|
| **손익분기 매출** | 고정비 ÷ (1 − 원가율) | **관리회계 CVP 분석의 표준 공식.** 특정 논문이 아니라 **회계학 교과서 기본식** — 별도 실증 근거 불필요 |
| **월 순이익** | 매출 − (매출×원가율) − 임대료 − 인건비 − 기타비 | 위와 같은 CVP 구조. 세금·감가상각 제외 → 세전 영업이익에 가까움 |
| **투자 회수 기간** | 초기 투자비 ÷ 월 순이익 | 단순 회수기간법(가장 기본). 화폐 시간가치 미반영이라 실제보다 낙관적 |
| **임대료 추정** | ㎡당 임대료 × 평수 × 3.3 | 1평 = 3.3058㎡ (정의상 고정 환산값) |
| **밀도 보정** | 시설 수 ÷ 자치구 면적(㎢) | 지역 비교 시 면적/인구로 표준화하는 통계 기본 원칙 |
| **폐업 추세** | (2024 − 2022) ÷ 2022 × 100 | 같은 지역 시점 간 변화율 → 규모 효과 상쇄 |

👉 **핵심 답변:** "계산식은 회계학 교과서의 표준 손익분기(CVP) 공식입니다. 제가 임의로 만든 게 아닙니다."

## 데이터는 어디서 (앱의 `dataRows()` 에 전부 명시)

| 데이터 | 출처 |
|---|---|
| 폐업 통계 | 국세청 국세통계포털 |
| 임대료·공실 | 한국부동산원 상업용부동산 임대동향 |
| 유동인구 | 서울 열린데이터광장(생활인구) |
| 매출·객단가·점포·소비·인구 | 서울 열린데이터광장(상권분석서비스) |
| 주차장 | 전국주차장정보표준데이터 |
| 자영업 벤치마크 | 통계청 소상공인실태조사 |

모두 **공공데이터(공공누리 1유형)** — 출처 표시하면 상업적 이용 가능.

## ⚠️ 솔직히 말할 것 — "출처가 없는" 숫자 (앱의 `assumptions()`)

미팅에서 이건 **먼저 솔직히** 말하는 게 신뢰를 얻습니다:

- **원가율·인건비·창업비 기본값** = 통계가 아니라 **업종 표준 가정값**입니다. (예: 커피 원가율 30%)
- **객단가·매출분포·임대료·유동인구는 실측**이지만, 위 세 개는 **가정**입니다.
- 그래서 진단 화면에서 **사용자가 직접 입력해 바꾸도록** 만들었습니다.
- 판단 임계값(유동인구 상위 8위=긍정 등)도 "실무 감각"이지 검증된 기준이 아니라고 앱에 적어놨습니다.

👉 **핵심 답변:** "실측 데이터와 가정값을 화면에서 구분해 표시했습니다. 가정값은 사용자가 자기 조건으로 바꿀 수 있고, 정확한 출처 데이터로 교체하는 게 다음 과제입니다."

# B. 직접 수정하는 법 (초보)

## 1. 안전한 수정 vs 위험한 수정

| 🟢 바꿔도 안전 | 🔴 건들지 말 것 |
|---|---|
| 화면에 보이는 **글자(라벨·설명)** | `support.js` (화면 그리는 틀 — 직접 만든 게 아님) |
| **색상** 값 (`#1F6FEB` 등) | `frontend/vendor/` (React·Babel 원본) |
| **기준 숫자**(기본 급여 250, 임계값 등) | `data-bundle.js` (자동 생성 — 손대도 다음 갱신에 덮어써짐) |
| 문구·안내 텍스트 | API 키 (애초에 코드에 없음. Vercel 환경변수) |

## 2. 자주 바꾸는 것 3가지

**(가) 글자 바꾸기** — 예: "월 손익분기 매출"을 다른 말로
1. `frontend/index.html` 열기
2. Ctrl+F 로 그 글자 검색
3. 글자만 바꾸고 저장 (`< >` 태그는 건들지 말기)

**(나) 기본 급여 바꾸기** — 예: 250만 → 300만
- `index.html` 에서 `wage: 250` 검색 → `wage: 300` 으로

**(다) 색 바꾸기** — 예: 파란색 → 다른 색
- `--accent:#1F6FEB` 같은 줄에서 `#1F6FEB` 를 원하는 색코드로

## 3. 바꾼 걸 확인하는 법 (내 컴퓨터에서)

```bash
cd frontend
python -m http.server 8000
```
→ 브라우저에서 `http://localhost:8000` 열면 내가 바꾼 게 보임. (인터넷 배포 전에 미리 확인)

## 4. 되돌리는 법 (제일 중요 — 안심하고 실험하세요)

- 저장 안 했으면: **Ctrl+Z** (실행 취소)
- 이미 저장했는데 되돌리고 싶으면 (git 사용 시):
  ```bash
  git checkout frontend/index.html      # 이 파일을 마지막 커밋 상태로 되돌림
  ```
- **팁:** 크게 바꾸기 전에 파일을 복사해두면(`index.html` → `index_backup.html`) 언제든 되돌릴 수 있어요.

## 5. 규칙 3개만 지키면 안 망가짐

1. **글자만 바꾸고, `< >` 괄호·`{ }` 중괄호·따옴표는 건들지 않기**
2. **한 번에 하나만** 바꾸고 바로 확인 (뭐 때문에 깨졌는지 알 수 있게)
3. **모르는 줄은 그냥 두기** — 이해 안 되는 코드는 안 건드는 게 정답

---

너무 걱정 마세요. 글자·숫자·색 정도는 위 방법으로 충분히 직접 바꿀 수 있고, 되돌리기가 있으니 실험해도 안전합니다.
