# 외부 취약 코드 학습 데이터 소스 검토

대규모 학습에는 임의의 GitHub 저장소를 무차별적으로 수집하는 방식 대신, 공개적으로 배포되며 취약점 수정 이력 또는 라벨을 제공하는 데이터셋을 사용한다. 수집 과정에서는 소스를 실행하지 않고, 제공된 데이터베이스·메타데이터·수정 전후 함수만 읽어 함수 단위 학습 예제로 처리한다.

| 우선순위 | 데이터셋 | 적용 방식 | 확인한 공개 범위 |
| --- | --- | --- | --- |
| 1 | CVEfixes | 공개 데이터베이스의 수정 전·후 함수와 CVE/CWE 메타데이터를 읽어 학습·검증한다. | 2024-07-23까지 공개된 CVE에 연결된 12,107개 수정 커밋, 4,249개 프로젝트, 138,974개 함수라고 배포 페이지가 설명한다. |
| 2 | VulDeePecker | C/C++ 코드 조각의 공개 라벨을 별도 학습·평가 코퍼스로 사용한다. | 배포 페이지는 취약 17,725개 및 비취약 43,913개를 포함한 61,638개 코드 조각을 설명한다. |
| 3 | DiverseVul | 별도 다운로드 승인을 거친 뒤, 메타데이터의 공개 커밋·저장소 URL을 사용해 확장 코퍼스로 적용한다. | 배포 저장소는 7,512개 커밋의 메타데이터를 제공한다고 설명한다. |

CVEfixes를 기본 소스로 선택하는 이유는 공개 CVE 레코드에 연결된 수정 커밋·파일·메서드 수준 정보를 관계형 데이터베이스로 제공해, 임의 키워드만으로 취약 여부를 추정하는 방법보다 출처와 라벨을 더 명확하게 기록할 수 있기 때문이다. 원본 데이터는 [CVEfixes 저장소](https://github.com/secureIT-project/CVEfixes) 및 [Zenodo 배포본](https://doi.org/10.5281/zenodo.4476563)에서 확인한다. VulDeePecker와 DiverseVul의 공개 배포 정보는 각각 [VulDeePecker 저장소](https://github.com/CGCL-codes/VulDeePecker) 및 [DiverseVul 저장소](https://github.com/wagner-group/diversevul)에서 확인한다.

> 학습 데이터의 존재는 모델 성능을 보장하지 않는다. 모델 평가는 데이터셋 간 중복을 피하고 프로젝트·커밋 단위 홀드아웃을 유지해야 하며, 정밀도·재현율·PR-AUC 등 불균형에 강한 지표를 정확도와 함께 보고해야 한다.

## 안전 경계

모든 데이터 파이프라인은 다운로드한 소스 코드를 가져오거나 실행하지 않는다. 허용된 작업은 아카이브 해제, 텍스트 읽기, 데이터베이스 조회, AST·함수 범위 추출, 정적 라벨·메타데이터 처리, 모델 학습 및 평가뿐이다. 실제 시스템 접근, 네트워크 대상 스캔, 익스플로잇 실행 또는 자동 공격 행위는 수행하지 않는다.
