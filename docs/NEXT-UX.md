# 현재 다음 개선 우선순위

## 운영 전에

1. 고객 DB 실연결과 회사 개인정보 안내·보유 기간·삭제 작업·백업 복구를 검증. 현재 DB 수집은 기본 비활성입니다.
2. 관리자 DNS 공개는 직원별 인증·2단계 인증·권한 분리 이후. 지금은 추가 비용 없는 SSH 접속 방식입니다.
3. 이메일 발송의 실제 발신자 인증, 수신자 확인 및 자동 발송 남용 방어. DB 저장 성공과 메일 발송 성공은 별도로 표시합니다.

## 사용자가 덜 헷갈리게

1. 리포트 설문을 줄이고, 지원사업 미연결 시 지원 관련 질문을 건너뛰도록 흐름을 개선. 결과를 먼저 주고 필요한 정보만 요청합니다.
2. 상권 선택 후 현재 지역·업종을 여러 화면에서 일관되게 유지하고, 변경 시 기존 선택이 어떻게 처리되는지 설명합니다.
3. 시세 지표별로 가능한 지역 범위가 다릅니다. 지금은 제공 범위를 문구로 설명하며, 구×업종 시계열 데이터 확장이 먼저 필요합니다.
4. 모든 주요 흐름의 키보드·화면낭독기·밝은/어두운 테마·실물 휴대폰/태블릿 검수. 현재 일부 버튼성 span과 복잡한 차트 접근성이 남습니다.
5. 클릭률뿐 아니라 상권 비교 완료율·설문 제출률·이탈 지점으로 개선 효과를 확인합니다. 현재 클릭 집계만으로 개인별 퍼널이나 재방문율을 계산할 수 없습니다.

## 관리자 사용성

현재는 100건씩 다음 페이지와 현재 페이지 검색·CSV입니다. 데이터가 쌓이면 서버 날짜/업종 검색, 이전 페이지, 범위 지정 전체 CSV, 직원별 감사 로그 화면을 추가합니다. 전체 CSV는 이메일 대량 유출 위험이 있어 권한·재인증·감사와 함께 설계해야 합니다.
