개인정보 안내

회원가입은 사용하지 않습니다. 고객 정보 저장은 기본적으로 꺼져 있으며, 운영자가 회사 정보와 처리방침·DB를 설정한 경우에만 별도의 선택 동의를 받아 저장합니다.

이 브라우저에 남는 정보

최근 검색 지역과 화면 설정은 이 기기의 브라우저 저장소에 남습니다. 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다. 입력한 사업 조건은 화면에서 계산하며, 리포트 미리보기로 넘긴 정보는 세션 저장소에서 읽은 뒤 지웁니다. 다운로드한 파일은 사용자 기기에 남습니다.

서버가 처리하는 정보

서비스 요청 시 IP 주소를 요청 제한 목적으로 일시적으로 메모리에서 처리합니다. 웹 호스팅과 프록시의 접속 로그는 운영 환경 설정에 따라 남을 수 있습니다.

이메일 리포트

기본 배포본에서는 이메일 발송이 꺼져 있습니다. 발송 기능을 활성화한 서비스에서는 동의 후 입력한 이메일 주소와 선택한 분석 내용을 메일 처리업체 Brevo에 전송합니다. 운영자는 발송 기능을 열기 전에 운영 주체, 연락처, 보관·삭제 기준, 수탁 및 국외 이전에 관한 실제 처리방침을 게시해야 합니다.

설문·이메일 저장 (선택)

저장 기능이 활성화된 화면에는 운영자, 문의처, 보유 기간이 표시됩니다. 별도 저장 동의와 버튼을 누른 경우에만 설문 답과 이메일을 서버에 암호화하여 저장합니다. 동의 문구 버전과 제출·만료 시각도 기록합니다. 저장하지 않아도 분석과 파일 다운로드를 이용할 수 있습니다. 마케팅 수신 동의를 의미하지 않습니다. 조회·삭제 요청은 저장 화면에 표시된 운영자 문의처로 연락해 주세요.

이용 통계 (선택)

이용 통계 설정에서 허용한 경우에만 일부 버튼의 클릭 수를 날짜·버튼·기기 크기별로 합산합니다. 이메일, 설문 답, 입력값, 개인 식별 ID를 통계 DB에 저장하지 않습니다. 클릭 집계는 90일 보유하며 언제든 이용 통계 설정에서 이후 집계를 거절할 수 있습니다. 이미 합산된 익명 통계에서 특정 개인의 클릭을 구분할 수는 없습니다.

운영자의 보호 조치

관리자 접근은 제한하고 조회·내보내기·삭제 작업을 기록합니다. 실제 보유 기간에 맞춘 삭제 작업과 암호화 키·백업 관리는 운영자가 설정해야 합니다. 운영자는 서비스 공개 전에 회사의 실제 개인정보 처리방침을 게시해야 합니다.
