일 승하차(명)

지도를 불러오지 못했어요

카카오 지도 JavaScript SDK가 차단됐습니다. 대부분 배포 도메인 미등록 또는 앱키 오류가 원인입니다(이전에 자치구 지도를 SVG로 바꾼 것도 이 문제 때문).

  1. Kakao Developers → 내 애플리케이션에서 JavaScript 키 발급
  2. 플랫폼 → Web → 사이트 도메인에 https://<배포도메인> 등록(현재 Vercel 주소)
  3. 이 파일 하단 appkey= 값을 발급한 JS 키로 교체

그동안 자치구 단위 개요는 개요 지도(SVG)에서 정상 동작합니다.
